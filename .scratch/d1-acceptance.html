D1「在家管」验收手册

给完全不了解实现的人：7 个场景，从头点到尾。每个场景都是独立的，做完一个再做下一个。

一句话功能说明：以前你要换机器人的归属，得去机器人堆里翻；现在在设置页最下方有一段“花名册”，列出每家每台机器人，点一下就能换家，换错 5 秒内可撤销。

开始前只做一次（3 步）：
  1. 把 DSH Desktop 完全退出（托盘也退掉），重新打开。
  2. 在 DSH 里按 Ctrl+F5 强制刷新一次。
  3. 打开 设置 → IM机器人辅助，把页面拉到最底，找到一段标题叫 我这一屋 · 花名册 的区域。如果没看到，先停下来告诉我（说明功能没挂载成功，后面不用测了）。

场景 1看全：每家有哪些机器人，一眼看清

测的是“看”的部分：不用去别处翻，在自己家就把名下全部机器人看完。

步骤

  1. 打开 设置 → IM机器人辅助，拉到最底的花名册区域。
  2. 数一数有几个“家”（每个家是一个小分组，标题是人名，右边写着 N 台）。
  3. 点开每个家，看每台机器人那一行：有没有 渠道名（如飞书/QQ）+ 状态（在线/待确认/离线/未知）。
  4. 对照你记忆中各家的机器人，看看有没有少谁、有没有多谁。
通过标准：每个家都在，台数对得上，每行都有渠道名和状态；标题下还有一行小字“只看管谁归谁；开除不在这里”。
算失败：少了一家/少了一台；某行没有状态；或者花名册里出现了 开除/删除 按钮（家里不许放开除，有就是错）。

场景 2换家：把一台机器人转给别家（主流程）

测的是“换”的部分，也是最常用的动作：人不合适，顺手转交。

步骤

  1. 在花名册里挑一台你舍得动的机器人（建议先拿测试用的动），点它那行的 换家… 按钮。
  2. 弹出“选择目录”框：选一个别家的文件夹（不要选它现在的家），点确认/选择此目录。
  3. 弹出二次确认框，内容类似“把‘某某’从 A 家换到 B 家？”：逐字核对两家名字，确认是从谁家到谁家。
  4. 点 确认换家。
  5. 观察：页面顶部/底部是否弹出成功提示 + 一个带 撤销 按钮的横条。
  6. 先别点撤销，去看花名册：这台机器人是不是已经出现在 B 家分组里了？再去左栏看看对应行的状态徽标变没变。
通过标准：确认框两家名字写得明白；点确认后机器人真的搬到了 B 家；设置页和左栏两边都刷新了，所见即所得。
算失败：确认框没出现就直接搬了；两家名字写反/含糊；搬完名单没变（要手动刷新才变也算失败）。

场景 3反悔：确认框里点“取消”，一切不动

对抗式检查：零成本反悔必须真的零成本，取消不能偷偷写一半。

步骤

  1. 重复场景 2 的第 1～3 步，走到二次确认框。
  2. 这次点 取消（或者按键盘 Esc，或者点框外面的阴影，再试一次，三种取消方式轮着来）。
  3. 看提示：应该有一句“已取消，原样不动”之类的。
  4. 检查花名册：这台机器人还在原来家里，位置、数量都没变。
通过标准：三种取消方式都好用；取消后提示明确；机器人纹丝不动。
算失败：点了取消还搬家了；提示含糊不清；框关不掉。

场景 4救火：换错了，5 秒内点“撤销”搬回来

测安全网：手滑换错家，一键挽回。注意这个场景和场景 2 是连着的。

步骤

  1. 故意把一台机器人换到一个错的家（走完确认）。
  2. 成功提示横条还在时，立刻点上面的 撤销。
  3. 看提示：“已撤销，回到某某家”。
  4. 检查花名册：机器人回到了原来的家。
  5. 再做一次换家，这次等 6 秒以上（横条自己消失），然后回忆：横条上应该有一句“撤销超时，换家已落定”之类的提示。
通过标准：5 秒内撤销秒回原家；超时后明确告诉你“已落定”，不会假装还能撤。
算失败：撤销没反应 / 撤到了错误的家；超时了还显示能撤销；或者超时后没有任何交代。

场景 5瞎点：换回自己家、连换多台

对抗式检查：无效操作要被温柔拦下；连续干活不能互相打架。

步骤

  1. 挑一台机器人点 换家…，在选目录时故意选它现在的家，看系统说什么（应该提示“它已经在这里了”，不弹确认框）。
  2. 连续把 2～3 台机器人逐个换给不同的家（一次走完一台再走下一台），每台都确认成功。
  3. 最后检查：每台都在目标家里，数量对得上，没有串家。
通过标准：换回自己家被拦下且有提示；连换多台各就各位。
算失败：换回自己家也弹确认框走流程；连换后某台不见了或去了错的家。

场景 6左栏小房子：路过看一眼，动手去大的地方

测左栏入口：行里地方小，只许看、不许动手，动手请去设置页。

步骤

  1. 看 DSH 左边工作区列表的顶部头栏，找一个房子形状的小图标按钮（鼠标悬停显示“在家管”）。
  2. 点它：弹出一个只读小浮层，列出各家和台数。
  3. 检查浮层里：没有任何按钮能换家/删除，只能看；底部有一行指引“动手换家去：设置 → IM机器人辅助 → 花名册”。
  4. 按 Esc 或点浮层外阴影或点右上角 ×，浮层关闭。
通过标准：小房子找得到；浮层内容和设置页花名册对得上；纯只读，有指引，三种关闭方式都好用。
算失败：找不到小房子；浮层里能动手改东西；内容和设置页对不上；关不掉。

场景 7极端情况：名下没机器人 / 显示慢半拍

对抗式检查：空的时候不许白屏；数据过期时不许瞎写。

步骤（空态）

  1. 如果你有名下没有机器人的环境（比如全新测试区），打开设置页花名册：应该看到明确的空提示“名下还没有机器人”+ 一句去哪领人的指引，而不是空白一片。
  2. 如果当前每家都有机器人，跳过空态这一步（告诉我一声，我帮你造这个环境），不要为了测而删机器。

步骤（慢半拍）

  1. 留意机器人行里的状态：如果某行显示 未知（轮询失败），点它的 换家… 走完全流程。
  2. 系统应该拒绝动手并提示你刷新后再试，而不是顶着过期数据硬写。
  3. 如果所有行状态都正常，说明网络很好，这一步记“未触发”，也告诉我。
通过标准：空态有文案有指引；过期数据下写操作被拦住且理由说得清。
算失败：空态白屏；顶着“未知”状态照写不误；拦截提示不知所云。
