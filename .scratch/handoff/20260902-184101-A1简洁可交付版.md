## 2. 黑屏根因与修复（第一轮关键成果，务必理解）

* **根因**：`settings.section` 渲染器（`@deepseek-ai/dsh-client-ui-renderer`）用 `jsx(Comp, {...})`（即 `React.createElement(Comp)`）渲染注册组件——**Comp 必须返回 React 元素**。旧代码 `FleetSettingsTab() => FleetPanel()` 返回的是自定义 `h()` 建的**裸 HTMLElement** → React 抛 `Objects are not valid as a React child` → slot 边界 skip → 内容区空 = 黑屏；侧栏 label 只读字符串所以能亮。`FleetPanel` 内部 try/catch 捕不到（错误在 reconciler 层）。
* **修复**：`FleetSettingsTab` 改为 React 外壳——`useRef` 容器 + `useEffect` 内 `mount.appendChild(FleetPanel())`（先 `innerHTML=''` 防重挂），返回 `React.createElement('div', {ref, style})`。`var React = require('react')` 在 factory 顶部 try/catch 获取（dsh-im 产物同模式 `require("react")`）。
* **铁律**：`settings.section` 注册的组件**永远必须返回 React 元素**；现有全部业务 DOM 构建可经 React 外壳挂载，不必重写成虚拟节点。
* **rpc.call 两个坑**（已修，见 §3）：第 4 参是 **AbortSignal 本身**不是 `{signal}`；返回值是 **`{ok:true,value}|{ok:false,error}` 信封**，取数据须解 `raw.value`（dsh-im 的 `unwrapRpcResult` 同逻辑）。
