## Problem Statement

用户在会话里看不到当前工作区归属 Agent 的健康与绑定状态，一切靠猜；想验证 IM 通道通不通，得去 dsh-im 设置页翻找；多渠道状态只能靠读文字转换；发测试消息要么没入口，要么卡在"先去配个投递目标"。

## Solution

会话 Header 右侧常驻一枚呼吸点（C 变体）：平时零打扰，悬停知状态，点击展开详情卡——标题为自定义名（与面板同一套命名）、渠道明细按渠道成行（首字徽标＋状态，一眼定位）、单个"发测试消息"动作；有已保存目标直发，无目标时用已聊会话做草稿测试（1 个直发、N 个自选、0 个给指引），全程不撒谎；未绑定只看灰色指引，无死按钮。

## User Stories

1. 作为对话用户，我想在 Header 一眼看到当前 Agent 在线与否，以便确认再说话。
2. 作为对话用户，我想悬停圆点即知"谁＋什么状态"，以便不点开也心里有数。
3. 作为对话用户，我想点击圆点展开详情卡且卡片贴着按钮、不挡路，以便看完即关。
4. 作为多渠道用户，我想每个渠道各占一行（徽标＋状态），以便一眼定位是飞书还是 QQ 在线，不用读字转换。
5. 作为改名用户，我想面板改名后 Header 自动跟过来，以便两处名字永远一致。
6. 作为验证者，我想一键发测试消息到已保存目标并看到成功回执，以便确认通道端到端通畅。
7. 作为未配目标的用户，我想只有一个聊过天的会话时点一下即发（草稿测试、不存东西），以便零配置验证。
8. 作为多会话用户，我想多个可投递会话时先选再发，以便测试消息不误入工作群。
9. 作为新用户（没和机器人说过话），我想看到明确指引（先说一句话），而不是神秘失败，以便知道下一步。
10. 作为谨慎用户，我想离线/待确认时点击发送被直接拦截并明示原因，以便不等转圈。
11. 作为排障者，我想发送失败时看到平台原码（如 bot-not-connected），以便对症处理。
12. 作为未绑定用户，我想看到灰色指引且没有任何按钮，以便不被死按钮欺骗。
13. 作为任意用户，我想数据没到之前 Header 干干净净（不闪"未绑定"），以便不被误导。
14. 作为深色用户，我想圆点与卡片自动跟随主题且清晰可读，以便夜间可用。
15. 作为忙碌用户，我想状态 15 秒内自己更新、无需刷新，以便一直可信。
16. 作为键盘/读屏用户，我想圆点可聚焦、有标签，卡片可 Esc 关闭，以便无障碍使用。
17. 作为多开用户，我想切换会话时各家状态各显示各的、旧卡不串台，以便不 confusion。
18. 作为评审人，我想所有"没有"都有对应文案（无目标/无会话/离线/失败），而不是静默，以便行为可审计。
19. 作为评审人，我想看到"已发送"当且仅当平台真正接受，以便杜绝谎报。
20. 作为维护者，我想样式与面板隔离命名、卸载即净，以便功能可整体移除。

## Implementation Decisions

- 状态派生收敛为纯函数：时机三态（未就绪 hidden／未绑定 unbound／已绑定 full）、首选 Bot（在线优先）、渠道聚合行（同渠道取最优可达性，与 B1 同 verdict）、测试文案固定前缀＋Agent 归因。
- 命名解析复用面板同一套规则（全路径优先、旧目录名键兼容、无名回退目录名首字母大写），名表经内存缓存异步加载，失败回退目录名。
- 读快照只订阅单例连接流；写路径走 dsh-im 主动投递通道（目标列举、建议列举、草稿测试、正式发送），信封解包、按码抛错。
- 无目标分支：已保存目标优先；否则已聊建议（1 个直发、N 个回列表、0 个给指引）；草稿测试不创建不保存任何目标。
- 挂载于会话 Header 工具槽列表位，order 30，异常降级（服务缺失/老宿主）只隐藏自己，不影响原生 Header 与设置面板。
- 事件契约：成功发送派发命名发送事件（含工作区/Agent/机器人/渠道/目标），供后续联动消费。
- 样式走功能命名空间＋主题别名跟随深浅色；浮层相对按钮锚定；外部点击/Esc/切会话关闭。
- 时机状态机（原型结论浓缩）：未就绪→hidden 不渲染；已知无绑定→unbound 灰色指引无动作；已绑定→full 呼吸点加详情。
- 无意义动作不设按钮（在场内自开工作区），无官方能力的跳转不做（设置导航经独立调查确认缺失，未绑定只静态指引）。

## Testing Decisions

- 只测外部行为，不测实现细节：纯数据断言跑转译后模块（prior art：B1 徽标模型测试同范式）；真 React 跑构建产物断言槽位注册与三态渲染（prior art：设置面板渲染验证）。
- 回归钉：呼吸 keyframes 存在性、同名目录隔离、旧名键兼容、草稿流全分支、离线预检零 RPC。
- 不测：dsh-im 服务端行为（以其投递契约文档为准）、像素级样式、真机定位（走 7 场景验收）。

## Out of Scope

- dsh-im 侧卡片名体系；features/ 目录搬迁；性格 preset 键迁移；发送/打开事件的消费端联动；设置页直达导航；品牌 logo（用渠道色加首字徽标代替）；批量与多目标发送；图片与富文本投递。
