## 通道与样式合规

- **通道**：`slots`（manifest.ts:14 声明 `settings.section`）；`rpc`（三通电话 `imc.updateStatus/Check/Install` + 追加型 case `meta.update.set`，全经 `/im-companion` 桥）；`meta`（data.ts:145 只读 `loadMeta()`）；**未用 `subscribe`**——不搭 connection-stream，也不存在第二份数据轮询；另有 §4 记录的 window 事件（见下）。
- **事件**：`UPDATE_CENTER_HOST_EVENT` 不在四通道白名单内，但**契约 §4 已明文记录该通道与「传递活 DOM」这一首次语义及其债务**；T8 只读共享层常量、不自建事件名、且在 mount 末尾 `document.getElementById('imc-update-center')` 主动认领（view.ts:180-187, 273-275）——与记录一致，属**依记录使用**，不另记违规。
- **自开轮询**：`setInterval` 仅 data.ts:78 一处，判据 `isBusy(job.state)`（installing/verifying），周期 `max(UPD_POLL,UPD_POLL_MIN)=1000ms`，**至多一个表**，离开/终态 `syncPoll` 清 + `dispose` 二路清（data.ts:75-87, 161-165）；轮询只发 `UPD_STATUS`，不带 check。**符合 §4 轮询许可三条**（上游规定 / 状态机限定 / 非同一数据源）。
- **localStorage / sessionStorage：0 命中**；偏好写走 `meta.update.set` 端点，读走 `ctx.meta`。
- **DOM 越权：无**。`mount(host,…)/clear(host)` 只作用于 A1 为其专建的空容器内部（panel.ts:181）；`claimHost` 是只读查询；`changelog.ts:97 document.body.appendChild(overlay)` 是自建自删的 `.update-center-overlay` 模态层（先例 adopt/panel.ts:56、welcome-banner），不读写任何 A1 容器或面板其它区域。
- **样式**：唯一注入点 manifest.ts:15 `installFeatureStyles('update-center', CSS)`；styles.ts 全选择器前缀 `update-center-*`（42 条规则）；**无 `.af-*`**；**无 `#imc-update-center` / `.update-center-host` 选择器**（仅注释提及，容器样式归 A1）。验证器另有命名空间断言（T8 断言集内）。
