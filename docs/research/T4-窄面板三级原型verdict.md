# T4 · 窄面板三级原型 · Verdict（用户 2026-10-10 认可）

> 票：#109（父图 #105）· 技能：prototype（UI 分支）· 依赖：T3-spec #116（语义按 #116 执行）

## 1. 回答的设计问题

家 → 助理 → 单渠道机器人 三级，在**窄且不高**的配置面板（约 530 × 700 CSS px）里长什么样、点得通吗？

判定分支：**UI 分支**（"应该长什么样"），不是逻辑分支 —— 状态模型由 #116 冻结，原型只回答呈现与交互。

## 2. Verdict（用户明示：认可当前原型）

1. **容器约束进原型**：面板按真实尺寸做（宽 ~540px、高随视口、内部滚动），不再用"整页文档"宽度。这是本次最大的修正。
2. **导航用钻取，不用平铺**：L1 家列表 → 点进 L2 助理列表 → 点进 L3 助理详情；面包屑常驻显示三级链路。
3. **弹层用锚定 popover，禁用底部弹窗**（用户偏好）：编辑/选择/确认都贴着触发点弹出；modal 只留给"走查/状态外显"两个大面板。
4. **TAB 可向前钻取**：列表页点 L2/L3 标签＝进入**当前焦点 item** 的下一级；焦点 = 悬停行 ＞ 键盘聚焦行 ＞ 已选中项；标签实时显示将进入的对象名。
5. **旧面板能力全部继承**：在线状态（绿点）、接入、详情、重命名、更换头像、更换工作区（＝旧"更换工作区…"）、移除渠道、路径展示。
6. **列表页信息增强**：家行显示"助理：小帅、客厅"（下面有哪些助理）＋ 在线汇总；每个 item 行内常显快捷操作。

## 3. 冻结的交互契约（T6 照此实现）

| 项 | 冻结内容 |
|---|---|
| 层级模型 | L1 家（=1 工作区）→ L2 助理（=1 机器人）→ L3 助理详情 |
| 进入方式 | 点行进入下一级；点 TAB 向前钻取（跟随焦点 item） |
| 返回方式 | 头部返回键 / 点 TAB 的上级 |
| 底部主操作 | 随层变化：L1 新建家 · L2 新建助理 · L3 绑定机器人 |
| 行内快捷操作 | 常显（不藏 hover）；窄于 470px 自动收纳进 ⋯ |
| 家族操作 | 重命名 / 更换头像 / 助理清单 / 恢复默认名 / 重连工作区 |
| 助理操作 | 接入 / 详情 / 重命名 / 更换头像 / 更换工作区 / 恢复默认名 / 移除渠道 / 删除助理 |
| 破坏性操作 | 一律 popconfirm 二次确认；删除类给 toast + 撤销 |
| 命名回落 | 家：用户手改 ＞ 工作区名 ＞ 目录基名；助理：用户手改 ＞ 机器人名 ＞ 家名（#116） |
| 具名冻结 | 改过一次即冻结，工作区/机器人再改名不跟随；可"恢复默认名"打回 |
| 状态语义 | 在线/离线（机器人）· 已绑/未绑定/失联（助理）· 待重连/暂存（家） |
| 术语 | 禁用"孤儿/复活/被删"；改用 待重连（家）/ 失联（助理）/ 重连 / 移除渠道 |

## 4. 交互与动效清单（已验证）

- 弹层族：popover（锚定+箭头+方向自适应左/右展开）、dropdown、popconfirm、tooltip、toast（可拖拽、可撤销、带进度）、modal、skeleton、spinner、progress、result。
- 动效：弹性入场/退场、液签（面包屑指示块）滑动、行删除后 FLIP 补位、接入流程 转圈→进度→结果。
- 鼠标：hover / active 缩放 / focus-visible 环 / 右键上下文菜单 / 禁用态 / 选中高亮；主按钮磁吸；详情卡 3D 视差（±5°）。
- 无障碍：`prefers-reduced-motion` 全关动画；`aria-current` / `aria-selected` / `aria-expanded` / `aria-modal`；Enter/Space 触发行；Esc 关弹层。

## 6. 实现时必须重做/注意（原型不能证明的部分）

- 头像：原型用色板示意，实现走**图片文件化 + 路径入库**（#116）。
- 面板真实尺寸取决于宿主 slot 实际给的大小；原型按 ~530×700 估算，实现需实测后调整断点。
- 数据全部是内存 mock；接入/掉线/改名等副作用在实现里要接真实 RPC 与 `stream.refresh()`。
- 跨系统非原子（新建工作区 + 落家）的失败态与回滚属 T6，原型未覆盖。
- 键盘可达性与屏幕阅读器只做了基础属性，实现时需完整走查。
