## 7. theme.ts（293 行）与深色适配

- 唯一样式来源（theme.ts:1-5）：TOKEN_BLOCK 12 个 --af-* 令牌全部由 --dsw-alias-* 实时派生（brand/label/bg/state 四组别名，theme.ts:8-21），项目自身无硬编码 #fff/#000 固定色（头像渐变 af-av-0..7 与二维码框 #fff 为例外：纯装饰/扫码对比所需）。
- 深色适配现状：全靠别名跟随，CSS 内无 @media (prefers-color-scheme) / [data-theme] 分支；表面/描边/文字均经 color-mix 由 label-primary 与 bg-base 派生（--af-surface/-surface-2/-hairline 系列），截图深色即别名在深主题下的取值；color-mix 需现代 Chromium（DSH 桌面端满足，旧浏览器降级未覆盖）。
- 排版：Apple 系字体栈（-apple-system/SF Pro/PingFang SC/Noto Sans SC，theme.ts:29-30）；大标题 30px/700（af-title）、计数行 13px tertiary（af-title-meta）；分组圆角列表 14px 圆角 + hairline 描边（af-list）；行内 72px 处 hairline 分隔线（af-row + .af-row::before）；状态点 8px + 光晕（af-dot 三态）；胶囊 11px（af-chip）、工作区行 11px tertiary（af-ws-line）；弹窗 18px 圆角卡片 + 50% 黑遮罩（af-modal/af-overlay）；toast 底部 pill（af-toast）。
- 安装：installStyles() 幂等挂 #dsh-im-companion-styles（data-gen 代戳防热重载误伤，theme.ts:270-293）；installFeatureStyles(id, css) 按功能命名空间挂 af-feature-<id>（theme.ts:286-288），首屏自身样式全部内联于 CSS 常量，无外部表。

## 9. af- 样式命名空间现状

- 全 af- 前缀：首屏所有组件类与 --af-* 令牌均在 af- 命名空间下（grep src/client 得 246 处命中、约 85 个去重类，全部以 af- 开头；入口类 af-root/af-list/af-row/af-btn/af-menu/af-toast/af-modal/af-overlay 等见 §6 表）。
- 修饰子类例外（非污染）：.active/.confirming/.danger/.primary/.tinted/.ghost/.sm/.online/.warn/.offline/.retry/.short/.fallback 及骨架内 .c/.lines/.b 均为 af- 父类下的组合/后代选择器（如 .af-btn.primary、.af-dot.online、.af-skel .b），不作为全局裸类使用；grep 未见裸 .btn/.row/.list/.modal 等占用。
- 隔离机制：STYLE_ID=dsh-im-companion-styles 全局单标签；feature 样式经 installFeatureStyles(id) 挂 af-feature-<id> 独立标签（theme.ts:286-288），军规 §1-⑥ 禁占用 .af-* 私有约定——T3 变体若新增类，必须用新前缀或 af-feature-<id> 通道，不得复用既有 af- 类名改语义。
- 事件命名空间（非样式但同理）：FLEET_VIEW_EVENT=dsh-im-companion:fleet-view（config.ts:29）、OPEN_DRAWER_EVENT=dsh-im-companion:open-drawer（config.ts:22）、OPEN_AGENT_EVENT=dsh-im-companion:open-agent（bindings.ts:11），均为 dsh-im-companion: 前缀。

## 10. 不动行为禁区（T3 变体避让清单）

以下只列事实（位置 + 语义），不做设计评判；T3 只动视觉/布局/文案，碰到即停：

1. 15s 轮询双源：panel.ts:83-85 setInterval 15000 → data.load(true) 静默刷新；connection-stream.ts:6 CONNECTION_POLL_MS=15000 + :57 setInterval 为 client 唯一轮询源（feature 经 subscribe 读，禁自开轮询）。静默失败保留旧数据（panel-data.ts:47-60，connection-stream.ts:42-54），静默轮询不闪骨架屏。
2. 绑定 RPC（fleet-api.ts）：fetchBots/fetchChannelStatus 并发调各渠道 `connection.status`（5s 超时，fleet-api.ts:58/157/167-188）；信封解包 ok:true.value（fleet-api.ts:139-143）；失败渠道 failed 记名，ok:false 为权威空不保留快照；mergeStaleBots 保留失败渠道旧快照标 stale=warn（fleet-api.ts:229-236）。写操作：panel-actions.ts:72 bot.workspace.set、:82 bot.delete（8s 超时），均走 ctx 的 rpc.call（panel.ts:102-108 / rpc.ts:5-11 只读透传）。
3. 接入流程（connect-flow.ts:1/29-39）：渠道菜单 → provision.begin 二维码（倒计时/轮询）→ 新机器人就绪 → workspace.set 绑定；全程 modal + timers，失败 toast 不抛。T3 不得改步骤、RPC、超时与绑定语义。
4. 数据层语义（model.ts）：1 Agent = 1 Workspace（用户 2026-09-02 拍板，model.ts:1-2）；按 Agent 按 workspace 全路径分组（含 unbound:botId 与 meta.locals 本地空壳，model.ts:130-179）；按渠道按渠道→工作区分组（model.ts:184-222）；健康合并任一在线即在线（mergeStatus，model.ts:74-78）；排序 agent 态按状态 rank + 中文名，channel 组内按中文名（model.ts:180/216）；计数 counts.agents/channels + totalBots（model.ts:42-47/181/222-229）。
5. 元数据与绑定语义：meta.ts（names/avatars/locals/presets/ctxEnhance/welcomed，host 桥 RpcMetaStore meta.* 或降级 localStorage，meta.ts:1-3/44-59）；改名/头像/本地增删全经 MetaStore 接口（panel-actions.ts:36-147）；头像键 本地 local:name / 非本地 workspace||base（panel-actions.ts:152-154），4MB 限 + 最长边 256px JPEG0.85 压缩（panel-actions.ts:157-184）。bindings.ts:48 badgeForWorkspace 只读算徽标（online/warn/offline/unbound），stale 按未知展示不谎报离线。
6. 装配与事件契约：slots.inject('settings.section', order 22, IM机器人辅助)（index.ts:105-113）；FLEET_VIEW_EVENT（radar 切矩阵）、OPEN_DRAWER_EVENT（详情开抽屉）只派发不直调（panel.ts:93-100，agent-row.ts:120-129）；HeaderOverlay/抽屉/矩阵/横幅/徽标均为域外面（map #22 Out of scope），T3 不得触碰。
7. 共享层 Added-only（features-contract §1-④）：theme.ts 只许追加类、model.ts/config.ts 只许加导出/字段；禁改既有签名、行为、重排与 af- 类语义。
