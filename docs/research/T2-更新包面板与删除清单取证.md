### 2.3 宿主最小接线（来源：解包 `README.md` §2 + `dist/host.d.ts`）

```js
import { createHostUpdate } from 'dsh-plugin-update'
const update = createHostUpdate(
  { ctx, logCtx },
  { pluginId: 'my-notes-plugin', prefix: 'notes', targetPackageName: 'my-notes-plugin' }
)
for (const [name, handler] of Object.entries(update.handlers)) {
  registry.set(name, handler)   // 电话名从 update.phoneNames 读，不自己拼字符串
}
```

- `pluginId` 必填（非空、不含路径分隔符；单例复用键含插件标识）。
- `prefix` 不传即 `wf`（历史值），新插件必须传自己的；电话名 = `<prefix>.updateStatus|updateCheck|updateInstall|updateChangelog`（`buildPhoneNames(prefix)` 拼出，面板侧从同一 prefix 算出）。
- 第二参数 `{ ctx, logCtx }` 外可加 `pluginManager` / `readerOverrides`；**平时只用 `readerOverrides.targetPackageDir` 逃生口**（hoisted/多副本/开发态链接才用）。包按包名在自己 `node_modules` 链上找目标包，反推使用范围目录（README §1）。
- ESM 直接 import；CJS 用 `await import()`。
- 四电话契约（README §2 表 + `host.d.ts`）：

| 电话 | 入参 | 成功回包 | 说明 |
|---|---|---|---|
| `.updateStatus` | `{}` | `{ ok:true, snapshot, manual, receipt:null }` | 只读本地 |
| `.updateCheck` | `{}` | `{ ok:true, snapshot, manual, receipt }` | 用户点了才联网；`receipt={checkId,checkedAt,expiresAt}` |
| `.updateInstall` | `{ checkId, requestId }` | `{ ok:true, snapshot, manual, receipt:null }` | `requestId` 面板生成，重复提交幂等 |
| `.updateChangelog` | `{ version }` | `{ ok:true, version, markdown: string\|null }` | 该版 tarball 内更新日志全文，取不到回空 |

- 失败一律 `{ ok:false, error, errorKind, diag? }`；`error` 14 码（8 阻塞 + 5 电话 + internal），分支只认 `errorKind`；`diag` 可选、1KB 内、旧面板忽略。
- `snapshot` 六字段（`ports.js`，面板 `PanelViewInput.snapshot` 消费）；`manual` 为手工命令（能给则给，否则 null）；`PhoneEnvView`（`includeEnv` 选填）：只回 `{ profileName, environmentKind }`，不回路径。
- `HostUpdate` 类型（`host.d.ts` 尾部）：`{ phoneNames: Record<PhoneAction,string> & Record<ChangelogPhoneAction,string>, handlers: Record<string,(args)=>Promise<…>> }`；另有 `__resetSharedUpdateReaderForTests()`（测试复位）。

### 2.4 检查更新按钮 `mountUpdateEntry`（来源：`dist/entry.d.ts` 120 行 + README §2.5 + `dist/entry.js` 实现核对）

签名：`mountUpdateEntry(container: UpdatePanelContainer, options: UpdateEntryOptions): UpdateEntryController`

- `container`：只要有 `innerHTML` 即可（浏览器元素或测试替身）+ 可选 add/removeEventListener。
- 必填：`pluginId`、`prefix`、`call: (name, args) => Promise<unknown>`。
- 四自由度（默认值都选好）：

| 自由度 | 取值 | 缺省 | 说明 |
|---|---|---|---|
| `variant` | button/badge/inline | button | 按钮 / 状态点 / 整块内嵌 |
| `autoCheck` | mount/never | mount | 进页面静默查一次（**只调 `.updateStatus`，只读**，实现 `entry.js: autoCheck ?? "mount"` 已核对） |
| `openOn` | has-update/always/manual/direct | has-update | 有新版才开面板 / 总是开 / 交 `onActivate` / 点开即弹窗不预查（面板挂载自查；实现已核对四值校验抛错） |
| `upToDateDisplay` | button/tooltip/note | button | 版本即按钮本身（0.8.0 新增）/ 收进悬停 / 右侧小字旧样 |

- 文案随状态自变（单语：中文界面纯中文、英文纯英文）：`检查更新` / `已是最新 X.Y.Z` / `有新版 1.1.0` / `正在安装…` / `待重启` / `更新失败，点此查看`；`entryStateKind({snapshot,error})` 五档：idle/update/busy/restart/failed（活任务 > 失败 > 待重启 > 有新版 > 待查；失败码是新证据、快照是旧读数，新证据赢 #91）。
- `controller`：`refresh()`（只读重查）/ `open()`（dialog 开面板）/ `close()` / `label()` / `setTheme()` / `setThemeTokens()` / `unmount()`（停订语言、停轮询）。
- `sizing`（#69：只改按钮本体）：`{ fontSize, padding, borderRadius, scale }`，等价手写 CSS 变量 `--dsh-update-entry-{font-size,padding,border-radius,scale}`；badge/inline 不受影响。
- `theme/themeTokens/locale/profileName/pollMs/autoChangelog/changelogMarkdown` 与面板同口径透传（入口件打开的 dialog 同步生效）。
- **铁律**（README 原文）：检查只读、安装写入，两者不许合并；入口件永远只做「查 + 打开面板」。
- 批量入口件（`entry-batch`，`mountUpdateBatchEntry`，聚合 N 家 `忙>失败>待重启>可更新>待查`）**与本仓无关**（本仓只管自己一家），迁移不引入。

### 2.5 dialog 面板 `mountUpdatePanel`（来源：`dist/panel.d.ts` 381 行 + README §第4步 + `dist/panel.js` 实现核对）

签名：`mountUpdatePanel(container, options): UpdatePanelController`（`panel.js: function mountUpdatePanel(container, options)` 已核对存在；`renderUpdatePanelHTML / UPDATE_PANEL_CSS` 同文件导出）。

- 必填：`pluginId`（与宿主侧一致）、`call: (phoneName, args) => Promise<Record<string,unknown>>`（面板唯一的宿主接触面）；`prefix` 缺省 `wf`（必须与宿主侧一致，电话名从它算）。
- `mode`: `embedded`（缺省）/ `dialog`——同一内核只换外层包裹；`setMode()` 运行时切换。
- dialog 关闭落地 `onCloseRequested`：dialog 下点关闭/Esc 先调它撤 DOM 再停轮询；不传则只停轮询。**入口件 `open()` 打开的 dialog 已内置**（收 dialog + 还原按钮 + 重查一次）——本仓若走“入口件按钮 + dialog 面板”路线，关闭逻辑零自写。
- 挂载即自查一次（首绘 loading → 只读本地刷新 → 有活体快照则条件自动查；抑制谓词 `pendingAutoCheck(snapshot, busyAct)` 为纯函数，仅 installing/verifying 或在途时不发起；实现见 #46/#48）。
- `controller` 全表：`refresh()` / `act(kind, arg?)`（`check|install|skip|reset-skip|copy-manual|copy-diag|toggle-queue|toggle-changelog|restart-hint|close-view|dismiss-failure`，与 HTML data-action 一一对应）/ `setMode` / `setTheme` / `setThemeTokens` / `setShowOthers` / `setChangelogCollapsed` / `setChangelogMarkdown` / `unmount()`（只停轮询拆监听，绝不中断安装）。
- 面板五章恒在（缺内容给中性提示，不跳号）：01 检查与安装 / 02 更新日志 / 03 更新队列 / 04 错误信息 / 05 手工命令；档案头「插件名 + 使用范围 + profile 牌」（`profileName` 显式覆盖优先，否则 includeEnv 索取，都没有显“未知”绝不猜）。
- 主题：`default`（最小可用深色）/ `archive`（档案卷纸面浅色，DOM 顺序不动）；`normalizePanelTheme` 非法归 default；`UpdateThemeTokens` 35 语义键 ↔ `--dsh-update-*` 变量（文字背景边线/主色焦点/状态四组/批量新版 newText+newOkText/字体阴影/圆角/入口件尺寸），非法挂载即抛；被覆盖 token 不再跟随深色模式。
- 02 章更新日志（#38/#23）：`autoChangelog` 缺省开（有新版调一次 `updateChangelog`，显式文本赢，false 退手动）；缺日志永不挡安装。
- 失败语义：14 码 `failureCopy/blockedCopy` 单语；失败横幅常驻到下一次用户主动查/装的新结论；`dismiss-failure`（知道了）只清提示不调电话；复制诊断 `buildUpdateDiagCopy` 脱敏、恒 1500 字预算（`PANEL_DIAG_MAX_CHARS`）；无失败时复制当前快照不伪造失败码。
- 跳过：面板本地 `PanelSkipStore`（`createMemorySkipStore/createBrowserSkipStore`，按版本记）与宿主侧 `skipped.json` 是两套，互不干扰。
- 排队：`showOthers` 缺省 false（只看自己，他人占位）；轮询 `pollMs` 缺省 1000、下限 250（`PANEL_POLL`，实现与宿主同一套）；`onRestartRequested` 可选（缺省只提示手动重启）。
- 只读渲染开关 `renderUpdatePanelHTML(input, { actions: 'none' })`：给调用方自供动作面的场景（批量详情用；本仓若自拼页面才需要）。
- HTTP 版（无 host.call 环境）：`mountUpdatePanelHttp({ pluginId, prefix, baseUrl, … })`——本仓有 host.call，用不上，仅备查。
