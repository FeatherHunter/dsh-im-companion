## Q1 已知原因 vs 未知失败的区分

**分得开，且两条通道同一词表**：已知原因走 `blocked`（#9 扁平 `errorKind`、#10 内层载荷、#11 嵌套 `details.update.error` —— 三处都命中「当前是从源码安装的…」文案），`pending-restart` 单独走 `restart`；未知失败一律 `unavailable` 并带原话/兜底句（#1–#8），`blockedTokenOf` 对 #8 返回 `null` 而未猜原因。分界判据是 token 是否存在（非空），空串 token 是唯一漏网的窄缝（边界项）。
