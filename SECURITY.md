# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

- Report via a private channel to the maintainers (see the repository
  contact links on the GitHub repo page).
- Include the affected version, a description of the issue, and steps
  to reproduce where possible.

We will acknowledge receipt and coordinate a fix and disclosure timeline
with you.
