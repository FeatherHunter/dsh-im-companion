左栏工作区悬浮卡 · 三态视觉原型

按维护者拍板（Q1=A 单票 / Q2=A 轻量：面板家身份 + 轻量分隔线、不加文字标签 / Q3=B 无 bot 也出卡 / Q4=A 两档游离标识）画的静态原型，真机数据取自 #190 复现条。点头后才改 src/features/left-badges/。

身份规则与面板同源：家＝房子图标 + 家色板（有上传图则用图）；助理＝机器人字形 + 暖亮色板；游离机器人＝渠道 logo（未知渠道回落灰色机器人字形），不用助理名/脸。

浅色主题对照（同一套规则，颜色走主题变量）

左栏悬浮卡在浅色主题下同样成立：分隔线、灰化未绑定、机器人行都不依赖固定底色。

这版原型要你确认的点

  1. 家行：房子图标＋家色板（与面板家行同规则），有上传图则显示图；家行与下面行之间只有一条轻量分隔线，不加「HOME/家」文字标签。
  2. 未绑定助理：淡色虚线头像＋灰化名＋右侧「未绑定」小标签，不挂渠道 logo、不挂状态点（二次验收反馈①）；已绑定助理行 = 渠道 logo＋助理身份头像（有配置头像显示头像）＋名＋状态点。
  3. 游离机器人：首格＝渠道 logo（未知渠道回落灰色机器人字形）＋机器人显示名，两档标签「未归属」（匹配到助理但助理属于别家）/「无助理」（完全匹配不到助理）；保留真实状态点；都不使用助理名/助理脸（二次验收反馈③）。
  4. 助理行头像已统一为面板助理身份（机器人字形＋暖亮色板）；有配置头像时显示头像（二次验收反馈②已按此实现）。
