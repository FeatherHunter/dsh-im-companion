L1 家行 · 三套方案

你提的三点，三套方案都解决了；差别在信息层级与视觉重量——选你更想要的那种手感。下面是真机深色主题、真机绿框样式（逐字摘的 home-ui-styles.ts）渲染出来的效果，不是示意图。

① 状态不够醒目「工作区已不在」现在是一枚灰底灰字的章，扫一眼看不见。
② 计数与默认规则「0 位助理」是纯文本、不成形；「跟随工作区名」是默认规则，不必写出来。
③ 家有助理时L1 的 item 应把已有助理的头像与必要信息带出来。
✓ 孤儿态改成彩色警示章 ＋ 卡片层面给暗示 ✓ 计数变成有形状的徽章（0 也成形） ✓ 去掉「跟随工作区名/跟随目录名」，只有你改过名才标 ✓ 助理头像直接进 L1 行
A

徽章化

最小的改动：一行主信息 ＋ 一行「头像叠堆 ＋ 计数章」。状态用警示章 ＋ 左侧细色条。
  • 「工作区已不在」→ 琥珀警示章（加 ⚠ ＋ 描边），并在卡片左侧加 3px 琥珀细条、底色淡淡染一层。
  • 「0 位助理」→ 计数章；0 时是虚线空章 ＋ 一枚「＋ 建助理」虚线动作胶囊（零态也有去处）。
  • 删除「跟随工作区名／跟随目录名」；只有你手动改过名才挂一枚灰 tag「你取的名」。
  • 助理头像以 20px 叠堆出现在副标行首（最多 3 个 ＋「+N」）。
改动量：小（行结构不动，只换副标内容 ＋ 加两枚章）。风险最低，观感最接近今天。
B

助理条带

家卡变两段式：上面是「头像＋名字＋计数」，下面一条 助理条带（头像＋名＋在线点）。
  • 助理从「一行灰字『助理：dsh-log』」升级成 芯片：圆头像 ＋ 名字 ＋ 在线点；未绑定的芯片虚线。
  • 空家不写「0 位助理」，直接给 虚线添加位「这个家还没有助理 · 建一个」——零态就是入口。
  • 孤儿家：条带位置换成琥珀提示行（⚠ ＋ 原目录路径 ＋ 行内「选择工作区 / 删除家」）。
  • 名字旁的「跟随…」全删；计数只在 Chip 数量上体现，不再单独写一句。
改动量：中（卡片从单行 grid 变成两段，行高会变，但信息最完整）。助理多的家最好看。
C

状态优先

整卡按状态着色：左侧 4px 色条 ＋ 孤儿底染；右侧常驻头像簇 ＋ 大计数方块，一眼看规模。
  • 状态做成整行编码：绿条＝正常、琥珀条＝工作区已不在、灰条＝没有工作区；孤儿整卡淡琥珀底。
  • 计数做成 26px 数字方块（0 是虚线空心方块），右侧与头像簇并排——「这个家多大」不用读字。
  • 副标只剩必要信息（在线数／原目录），默认命名规则一个字都不写；改过名才挂 tag。
  • 助理头像 26px 叠堆在右侧（最多 3 ＋「+N」），与头像簇一起构成「规模感」。
改动量：中偏大（要改行模板与间距），但状态区分最强，长列表里最好扫。
